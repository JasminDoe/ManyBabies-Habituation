ManyBabies Habituation Project

This project aims to explore infant habituation through looking times using a large harmonised dataset from ManyBabies 1, ManyBabies 3, and ManyBabies 4.

Date: 2026 05 31

Project overview

This project forms part of a multi team analysis project coordinated by Ingmar Visser. Study-relevant materials can be found on the Open Science Framework: https://osf.io/8xm4r.
