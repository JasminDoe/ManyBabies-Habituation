Create Overall Habituation Curve Models

To explore which functional forms best capture habituation trajectories, we model looking time as a function of trial number using a series of regression models. Specifically, we compare linear, quadratic, cubic and other shapes (using splines) relationships the variables.

First, we estimate a linear model to assess whether looking time decreases across trials. We then extend this model by including a quadratic term to capture potential curvature in the habituation trajectory. In addition, I fit flexible non-linear models using spline functions to allow for more complex shapes. Importantly, we always use mixed-models with infant-level random intercepts, to account for repeated measurements within infants.

Create Overall Habituation Curve Models with covarying dimensions for the spline outcome

To evaluate whether demographic variables (household size, language background, age, sex, and caregiver gender) modulate the habituation trajectory, we employed a confirmatory model-testing strategy. We first fitted a comprehensive ‘full’ model incorporating these factors as fixed effects and their interactions with the trial number (modeled via natural splines, \(df=4\)). We then utilized the drop1 procedure and AIC comparison to evaluate whether the inclusion of these parameters significantly improved model fit compared to a parsimonious baseline model (the habituation trajectory alone). This approach ensures that we do not overfit our models with demographic predictors that do not account for meaningful variance in infant looking time.

To verify that these null results were not an artifact of model specification, we conducted a sensitivity analysis. We systematically compared the baseline model (m0) against expanded models incorporating each demographic factor (both as main effects and as interactions with trial number). As shown in our model comparison results, none of these additions yielded a statistically significant improvement in model fit, further reinforcing the robustness of the baseline habituation trajectory.

As a result, model comparison revealed that the baseline habituation model—incorporating natural splines (df=4) for trial number and accounting for hierarchical random intercepts—provided the most parsimonious fit to the data. The inclusion of demographic predictors, including household size, language background, and caregiver gender, did not significantly improve model fit. These findings suggest that the habituation trajectory is a robust developmental phenomenon, independent of the demographic variations assessed in this study. Furthermore, this model specification maintains internal consistency with the analytical frameworks established in Q1 and Q3, facilitating cross-question comparability.

To complement our statistical findings, we examined the habituation trajectories visually. This allows us to move beyond abstract numbers and see if the decline in looking time follows a simple linear path or if it exhibits the more complex, non-linear patterns identified in our models. Specifically, by comparing monolingual and bilingual infants in Figure 1, we can evaluate whether the process of habituation—the rate and shape of the decline—differs by language background.

# --- VISUALIZING HABITUATION BY AGE ---
# We compare the habituation curves across age groups.
# We use natural splines (df=4) to ensure the visual lines match the 
# statistical models we tested earlier.

ggplot(data_q2_complete, aes(x = testing_trial, y = log(looking_time), color = age)) +
# 1. Plot raw group means for each trial
  stat_summary(fun = mean, geom = "point", size = 2) +
# 2. Add the non-linear spline trend for each group
  geom_smooth(method = "lm", 
              formula = y ~ splines::ns(x, df = 4), 
              se = TRUE, 
              alpha = 0.1) +
# 3. Label for clarity
    labs(
    x = "Trial Number",
    y = "Mean Looking Time (seconds)",
    color = "Age group",
    title = "Habituation Trajectory by Age Group",
    subtitle = "Fitted with Natural Splines (df=4) to match statistical models"
  ) +
  # 4. Ensure each trial number is labeled on the x-axis
  scale_x_continuous(breaks = 1:max(data_q2_complete$testing_trial)) +
  theme_minimal()

In Figure 1, the vertical distance between the teal and red curves indicates a baseline difference in total looking time between groups; however, because the curves are parallel, we conclude that the process of habituation—the rate at which infants lose interest—is identical for both monolingual and bilingual infants.
