1. Introduction

This analysis investigates Research Question 3: “Do methodological and measurement choices influence the estimation and interpretation of infant habituation?”. We specifically examine the seating arrangement (caregiver_seat), comparing infants in a caregiver’s lap (89.5% of observations) to those sitting alone (10.3%).

The goal is to determine if seating affects habituation while accounting for infant age, the experimental method used (e.g., Eye-tracking vs. HPP vs. Single-screen), and project-level differences across ManyBabies 1, 3, and 4.

2. Data Preparation and Zero-Inflation Handling

As noted in the MB project sources, infant looking times are often zero-inflated. To address this and meet project requirements for standardized coefficients, we: 1. Filter trials: Focus only on valid testing trials (testing_trial > 0). 2. Clean seating: Remove “changed_throughout” (n=54) and missing values. 3. Log-transform: Create log_looking_time to handle skew. 4. Scale: Standardize age_days and testing_trial to produce \(\beta\) coefficients.

Code 
# Load the raw data
data <- read.csv("final_merged_manybabies.csv")

data_rq3 <- data %>%
  # STEP A: Create 'testing_trial'
  mutate(testing_trial = ifelse(trial_number > 0, trial_number, NA)) %>%
  
  # STEP B: Create clean lab_id (lowercase, no special characters)
  mutate(lab_id = as.character(lab_id),
         lab_id = gsub("[^a-z0-9]", "", tolower(lab_id))) %>%
  
  # STEP C: Create 'age' with labels
  mutate(
    age = cut(
      age_days,
      breaks = c(0, 90, 180, 270, 365, 455, 545, 635, 653),
      labels = c("< 3 months", "3–6 months", "6–9 months", "9–12 months", 
                 "12–15 months", "15–18 months", "18–21 months", "> 21 months"),
      right = FALSE
    ),
    age = dplyr::coalesce(age_group_new, age),
    age = factor(age, levels = c(
      "< 3 months", "3–6 months", "6–9 months", "9–12 months", 
      "12–15 months", "15–18 months", "18–21 months", "> 21 months"))
  ) %>%
  
  # STEP D: Create 'age_group_clean'
  mutate(age_group_clean = recode(age,
                                  "15–18 months" = "15–21 months",
                                  "18–21 months" = "15–21 months",
                                  .default = levels(age))) %>%
  
  # STEP E: Filtering
  filter(
    !trial_type %in% c("TRAIN", "fam"),
    !is.na(age),
    !is.na(looking_time),
    !is.na(caregiver_seat),
    caregiver_seat != "changed_throughout" 
  ) %>%
  
  # STEP F: Final Formatting
  mutate(
    caregiver_seat = factor(
      caregiver_seat,
      levels = c("caregiver_lap_only", "seat_alone_only"),
      labels = c("Caregiver Lap", "Sitting Alone")
    ),
    method = factor(
      method,
      levels = c("eyetracking", "hpp", "singlescreen")
    ),
    trial_type = factor(trial_type),
    age_sc = as.numeric(scale(age_days)),
    trial_sc = as.numeric(scale(testing_trial)),
    log_lt = log1p(looking_time)
  )

3. Distribution Analysis: Checking for Confounds

A critical step in this analysis is determining whether caregiver seating is a truly independent variable or a proxy for other methodological choices. As noted in the sources, there is a significant structural imbalance in the ManyBabies dataset: infants sitting alone are heavily overrepresented in eyetracking data, while those on a caregiver’s lap are the standard in HPP and single-screen paradigms.

3.2 Quantifying Lab and Methodological Overlap

Beyond visual trends, we must statistically quantify the confounding between labs and seating. Because seating options are often fixed at the lab level, “Sitting Alone” might be confounded with unmeasured factors such as specialized equipment or researcher expertise in independent-sitting protocols.

This section identifies flexible labs (those using both seating types) to determine if the seating effect can be disentangled from lab identity.

Code 
lab_seating_summary <- data_rq3 %>%
  group_by(lab_id) %>%
  summarize(
    n_lap       = sum(caregiver_seat == "Caregiver Lap"),
    n_alone     = sum(caregiver_seat == "Sitting Alone"),
    total_trials = n(),
    is_flexible = n_lap > 0 & n_alone > 0
  )

total_labs        <- nrow(lab_seating_summary)

5. Statistical Models and Performance

5.1 Omnibus Model (Random Intercepts)

The omnibus model tests how infants’ habituation trajectories (nonlinear change in looking over trials; ns(trial_sc, 4)) vary through two targeted three-way interactions: one between caregiver seating and experimental method, and another between caregiver seating and age. The model also incorporates trial_type as a fixed-effect control to account for systematic differences in baseline looking times across MB project-specific stimuli (e.g. social, non-social). This model also accounts for individual differences in overall looking time (unique_subject_identifier, random intercept only) and the multi-level structure of the data across projects (project_id) and labs (lab_id). This model converged.

Code 
model_random_intercepts <- lmer(
  log_lt ~ ns(trial_sc, 4) * caregiver_seat * method + 
    ns(trial_sc, 4) * caregiver_seat * age_sc + 
    trial_type + 
    (1 | project_id) + 
    (1 | stimulus_id) +
    (1 | lab_id) +     
    (1 | unique_subject_identifier), 
  data    = data_rq3,
  control = lmerControl(optimizer = "bobyqa")
)

6. Conclusion

In the mixed-effects omnibus model, the fixed-effects coefficient for caregiver seating was positive and significant (b = 0.13, β = 0.18, p = .003), indicating that infants sitting alone (i.e. independently) showed higher log looking times than those on the caregiver’s lap at the model’s reference conditions (i.e., at mean age and the eyetracking reference paradigm). Because the omnibus model includes higher-order interactions with age, experimental paradigm, and trial progression, this coefficient represents a conditional baseline effect rather than a uniform main effect across all developmental stages and testing contexts. Critically, the sign convention of the post-hoc contrasts is reversed relative to this coefficient — a negative contrast estimate (coded as Caregiver Lap minus Sitting Alone) likewise indicates higher looking times for the Sitting Alone group.

The seating effect was strongly dependent on experimental paradigm. Post-hoc comparisons slicing the effect by method revealed that the higher looking times for infants sitting alone were significant exclusively within eyetracking studies (estimate = −0.10, z = −2.47, p = .013), and were absent in both HPP (p = .734) and single-screen (p = .756) paradigms. This pattern was further validated in an eyetracking-only model, which yielded a more pronounced seating effect (b = 0.28, β = 0.36, p < .001; note that these estimates are from a separate subsample model and are not directly comparable in magnitude to the omnibus estimates above).

Within the eyetracking context, the seating effect was present across the age range examined. Contrasts at three levels of standardized age showed that the looking time advantage for infants sitting alone was statistically significant at all ages: younger infants (age −1SD: estimate = −0.28, p < .001), mean age (estimate = −0.23, p < .001), and older infants (age +1SD: estimate = −0.18, p = .006). Although the magnitude of the contrast was numerically smaller for older infants, the two-way interaction between caregiver seating and standardized age was not statistically significant in the eyetracking-only model (p = .436), meaning the data do not provide clear evidence for age moderation of the seating effect. Any interpretation of a developmental gradient should therefore be treated with caution.

The effect of caregiver seating was also significantly qualified by its position within the habituation trajectory, and this pattern further varied by infant age. The caregiver seating effect altered the shape of the habituation trajectory itself, as evidenced by significant two-way interactions with the mid-session spline components (2nd degree: β = −0.18, p = .003; 3rd degree: β = −0.31, p = .007). Furthermore, these trajectory differences were subject to a developmental constraint, indicated by significant three-way interactions between the spline components, seating arrangement, and standardized age (2nd degree × age: β = −0.11, p = .042; 3rd degree × age: β = −0.29, p = .004).

Because spline terms represent non-linear transformations of the time variable, individual coefficients are not directly interpretable in isolation. Interpretation therefore focuses on the model-predicted trajectories, as visualized in Figures 5–7, which provide a more meaningful representation of how log looking time changes across trials as a function of caregiver seating condition and infant age. These predicted curves suggest that infants sitting alone begin with higher looking times and sustain this elevation across the session. Notably, habituation slope contrasts did not reach statistical significance (p = .280), and numerically the Sitting Alone group showed a slightly steeper decline (slope = −0.211) than the Caregiver Lap group (slope = −0.180). The current data therefore do not support the interpretation that the seating effect reflects differential processing efficiency over time; rather, seating arrangement appears to primarily influence infants’ initial baseline attention level.

A noteworthy finding in this exploratory analysis was the structural confounding between seating and lab identity. Diagnostic analysis revealed that only 13.4% of participating labs (15 out of 112) used both seating types, while the remainder relied exclusively on a single arrangement. This confirms that seating is predominantly a fixed methodological choice at the lab level. Accordingly, the reported differences may partially reflect lab-specific characteristics such as specialized equipment (e.g., eye tracker mounts, highchairs, harnesses) or varying levels of researcher expertise in optimizing infant comfort and cooperation. While the mixed-effects models account for lab-to-lab variability through random intercepts (lab_id variance = 0.05), the high degree of structural imbalance across the data set means the physical impact of the seating arrangement cannot be fully disentangled from broader lab-level characteristics.

The reversal between the raw, unadjusted data (Figure 3; where infants on the caregiver’s lap show longer looking times) and the model-estimated trajectories (Figure 4; where infants sitting alone show higher log looking times in some cases) underscores the importance of controlling for measurement method. Because sitting alone is heavily concentrated in eyetracking studies (25.1% of eyetracking trials) relative to HPP (1.7%), the sitting-alone advantage only becomes visible once systematic differences in data capture between paradigms are accounted for.

A further limitation is that within-subject autocorrelation across trials was not explicitly modeled. Because infants contribute repeated looking time measurements over successive trials within a session, observations closer in time may be somewhat more correlated than those further apart — a dependency that random intercepts alone, which assume compound symmetry, do not fully capture. That said, the habituation session spans only several minutes, which reduces the likelihood of strong temporal drift, and the inclusion of a natural spline over trial number as a fixed effect absorbs much of the systematic trial-by-trial trend. Nevertheless, future analyses could explore whether explicit autoregressive error structures (e.g., AR1, implementable via nlme or glmmTMB) alter the estimated seating effects, as a robustness check rather than a fundamental correction.

In conclusion, our analyses for RQ3 suggest that researchers should treat caregiver seating arrangement as a methodological covariate in analyses of infant attention, particularly in eyetracking studies. At minimum, we strongly encourage developmental researchers to consistently report seating arrangements to facilitate more accurate cross-study comparisons.
